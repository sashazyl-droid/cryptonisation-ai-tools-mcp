# Security policy

Supported version: 1.x.

Report vulnerabilities through the [contact form](https://aitools.cryptonisation.pro/contacts/) with the subject Security, or a [private security advisory](https://github.com/sashazyl-droid/cryptonisation-ai-tools-mcp/security/advisories/new) when enabled by the repository owner. Do not disclose vulnerabilities, credentials or private logs in public issues.

The wrapper exposes only three public read-only methods. It does not load administrative tokens or execute commands from catalog cards.
