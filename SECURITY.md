# Security policy

Supported version: 1.x.

Report vulnerabilities in the website, the API or the MCP server to [hello@cryptonisation.com](mailto:hello@cryptonisation.com) with "Security" in the subject, or through a [private security advisory](https://github.com/sashazyl-droid/cryptonisation-ai-tools-mcp/security/advisories/new). Please do not disclose vulnerabilities, credentials or private logs in public issues, and do not publish details before we have fixed the issue.

The wrapper exposes only three public read-only methods. It does not load administrative tokens or execute commands from catalog cards.
